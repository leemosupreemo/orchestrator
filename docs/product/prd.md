## Pitch
- Orchestrator (Beta) coordinates multiple machines and LLMs through one end-to-end development workflow: planning, implementation, review, testing, and delivery.
- Built for: a Mac that hosts it and runs the jobs, with browser access from any device; the projects it builds are iOS, Android and web apps; a macOS app is also present in the project.

## Who it's for
- Appears to be for software developers who want AI agents to help carry project changes from an idea or bug report through verification and delivery.

## Core features
- Create, import, or draft a short product requirements document from an existing codebase; break it into epics and jobs, with Jira support.
- Planner, verifier, builder, and reviewer roles support a structured, test-driven workflow.
- Run jobs locally or dispatch work to remote machines over SSH.
- Integrate with GitHub issues and pull requests, or use GitLab, Bitbucket, or plain git branches.
- Web UI and local console for projects, jobs, logs, builds, and distribution; browser actions run in a live terminal.
- Detect and configure Swift, Rust, Python, JavaScript/TypeScript, and Go projects, including Swift Package Manager and Xcode.
